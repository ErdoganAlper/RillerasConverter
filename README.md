# RillerasConverter

Convert images/PDF workflow utility built with Python.

## Features
- Convert supported input files
- Simple desktop usage
- Packaged as `.exe` with PyInstaller

## Requirements
- Python 3.10+
- pip

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python RillerasConverter.py
```

## Build EXE
```bash
py -m PyInstaller --onefile --windowed --name RillerasConverter RillerasConverter.py
```
